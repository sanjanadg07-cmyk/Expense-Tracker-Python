Expense Tracker

A simple Python-based Expense Tracker that helps users record, manage, and track their daily expenses.

Features

* Add and record expenses
* View stored expenses
* Track spending easily
* Simple and beginner-friendly interface
* Organized Python project structure

Technologies Used

* Python
* Git
* GitHub

Project Structure

```text
Expense-Tracker/
│
├── expense_tracker.py
└── README.md
```

How to Run

1. Clone the repository.
2. Open the project folder in VS Code.
3. Run the Python file:

```bash
python3 expense_tracker.py
```
